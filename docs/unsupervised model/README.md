# 非監督式異常偵測模型

本目錄包含 Stage II 異常偵測階段使用的四種非監督式學習方法的詳細說明。

---

## 模型概覽

| 模型 | 核心機制 | 優勢 | 適用場景 |
|------|---------|------|---------|
| [Isolation Forest](Isolation_Forest.md) | 幾何隔離 | 計算快、高維適用 | 稀疏異常點偵測 |
| [COPOD](COPOD.md) | 統計機率 | 無超參數、計算快 | 極端值偵測 |
| [AutoEncoder](AutoEncoder.md) | 重建誤差 | 非線性學習 | 語義模式偏離 |
| [PCA + GMM](PCA_GMM.md) | 密度估計 | 多模態建模 | 低密度異常 |

---

## 選擇指南

### 根據資料特性選擇

| 資料特性 | 推薦模型 |
|----------|---------|
| 高維嵌入向量 | IF + COPOD（不受維度詛咒）|
| 多種正常行為模式 | GMM（多模態建模）|
| 需要語義學習 | AutoEncoder |
| 小樣本資料 | IF（不依賴完整分佈）|

### 根據異常類型選擇

| 異常類型 | 推薦模型 |
|----------|---------|
| 罕見事件 | Isolation Forest |
| 極端特徵值 | COPOD |
| 語義偏離 | AutoEncoder |
| 低機率事件 | PCA + GMM |
