# COPOD (Copula-Based Outlier Detection)

## 概述

**COPOD（基於 Copula 的異常偵測）** 是一種統計機率驅動的非監督式異常偵測方法。其核心理念是：**透過經驗累積分佈函數（ECDF）評估樣本在每個維度上的極端程度，再結合 Copula 函數整合多維度資訊**。

COPOD 最大的優勢在於**計算效率極高**，不涉及迭代訓練或距離計算，特別適合大規模資料處理。

---

## 核心機制

### 經驗累積分佈函數 (ECDF)

對於每個特徵維度，COPOD 計算每個樣本的累積機率：

$$
F_j(x_{ij}) = \frac{1}{n} \sum_{k=1}^{n} \mathbf{1}(x_{kj} \leq x_{ij})
$$

- 結果範圍在 $[0, 1]$ 之間
- 接近 0 或 1 表示該維度上的極端值

### 尾端機率估計

COPOD 分別評估**左尾**與**右尾**的極端程度：

- **左尾異常**：$-\log(F(x))$，值越小 → 分數越高
- **右尾異常**：$-\log(1 - F(x))$，值越大 → 分數越高

### Copula 整合

Copula 函數用於整合各維度的尾端機率，產生總體異常分數：

$$
\text{Score} = \sum_{j=1}^{d} \max(-\log F_j(x_j), -\log(1-F_j(x_j)))
$$

此公式確保只要在**任一維度**上極端，整體異常分數就會提高。

## 演算法特性

### 優勢

| 特性 | 說明 |
|------|------|
| **計算效率極高** | 時間複雜度 $O(nd)$，無需迭代訓練 |
| **無需距離計算** | 避免高維空間中距離退化問題 |
| **可並行化** | 各維度 ECDF 可獨立計算 |
| **無超參數** | 除了 contamination 外幾乎不需調參 |
| **左右尾對稱** | 同時偵測過高與過低的異常值 |

### 限制

| 限制 | 說明 |
|------|------|
| **獨立性假設** | 假設維度之間相互獨立，忽略特徵相關性 |
| **均勻分佈敏感** | 當特徵呈均勻分佈時，ECDF 鑑別力下降 |
| **維度平權** | 所有維度權重相等，無法突出重要特徵 |

## 在本專案的應用

### 適用場景

COPOD 在本專案中扮演**統計檢驗器**的角色：

1. **多維極端值偵測**：識別在嵌入向量某些維度上呈現極端值的日誌
2. **快速初篩**：作為輕量級前置篩選器，減少後續重量級模型負擔
3. **異常解釋**：可追溯異常發生在哪些特徵維度

### 與 BERT 嵌入的契合度

BERT 嵌入向量的特性使 COPOD 特別有效：

| 嵌入特性 | COPOD 優勢 |
|----------|-----------|
| 高維度（768 維） | COPOD 不受維度詛咒影響 |
| 語義分散 | 極端語義在特定維度顯著 |
| 正規化向量 | ECDF 對數值範圍不敏感 |

### 互補性貢獻

在 Ensemble 策略中，COPOD 提供獨特的機率視角：

| 與其他模型比較 | COPOD 獨特性 |
|----------------|-------------|
| vs. Isolation Forest | IF 看整體空間位置，COPOD 看單維極端 |
| vs. AutoEncoder | AE 依賴重建，COPOD 直接評估機率 |
| vs. PCA+GMM | GMM 假設高斯分佈，COPOD 無分佈假設 |

### 日誌異常類型適用性

| 攻擊類型 | COPOD 偵測效果 | 原因 |
|----------|---------------|------|
| **異常命令參數** | ★★★★★ | 特定參數維度呈極端值 |
| **罕見系統呼叫** | ★★★★☆ | 語義嵌入在多維呈極端 |
| **微小行為變異** | ★★★☆☆ | 需多維同時極端才顯著 |
| **複雜多步驟攻擊** | ★★☆☆☆ | 各步驟可能不極端 |

## 統計學背景

### Copula 函數簡介

Copula 是一種多變數聯合分佈函數，用於描述變數之間的依賴結構：

$$
C(u_1, u_2, ..., u_d) = P(U_1 \leq u_1, U_2 \leq u_2, ..., U_d \leq u_d)
$$

其中 $U_i = F_i(X_i)$ 是將原始變數透過各自的邊際分佈轉換到 $[0, 1]$ 範圍。

### COPOD 的 Empirical Copula

COPOD 使用經驗 Copula（Empirical Copula）：
- 不假設特定的 Copula 家族（如 Gaussian、Clayton、Frank）
- 直接從資料估計邊際分佈
- 計算效率高，適合大規模資料

## 參數調整指南

### 關鍵參數

| 參數 | 建議值 | 影響 |
|------|--------|------|
| **contamination** | 0.05-0.1 | 預期異常比例 |
| **n_jobs** | -1 | 並行計算核心數 |

### 調整策略

COPOD 幾乎不需要調參，主要考量：

- **資料量小** → 結合其他模型，ECDF 估計可能不穩定
- **特徵相關性高** → 考慮先做 PCA 降維
- **需要可解釋性** → 檢查各維度的尾端機率貢獻
