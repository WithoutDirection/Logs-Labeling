# Isolation Forest

## 概述

**Isolation Forest（隔離森林）** 是一種基於樹狀結構的非監督式異常偵測演算法。其核心理念是：**異常樣本在特徵空間中較為稀疏，因此更容易被隨機切割隔離**。

與傳統方法（如 K-Means、DBSCAN）專注於建模正常資料不同，Isolation Forest 直接對「異常性」進行量化，計算效率極高。

---

## 核心機制

### 隔離原理

Isolation Forest 透過遞迴地隨機切割特徵空間來隔離樣本：

1. **隨機選取特徵**：從所有維度中隨機選擇一個特徵
2. **隨機選取切分點**：在該特徵的最大值與最小值之間隨機選擇一個閾值
3. **遞迴切割**：根據閾值將資料分為兩個子集
4. **重複直到隔離**：持續切割直到每個樣本被完全隔離

### 路徑長度與異常分數

- **路徑長度**：從根節點到將樣本隔離所需的切割次數
- **異常樣本**：由於在空間中分佈稀疏，通常只需少數幾次切割即可隔離（路徑短）
- **正常樣本**：在密集區域，需要更多切割才能隔離（路徑長）

異常分數計算基於平均路徑長度：
- 路徑短 → 異常分數高
- 路徑長 → 異常分數低

### 集成策略

單棵隔離樹具有隨機性，因此採用集成方法：
- 建立多棵隔離樹（通常 100 棵）
- 計算樣本在所有樹上的平均路徑長度
- 透過正規化產生最終異常分數

## 演算法特性

### 優勢

| 特性 | 說明 |
|------|------|
| **線性時間複雜度** | $O(n \log n)$，遠優於距離型方法的 $O(n^2)$ |
| **無需先驗知識** | 不需要預設異常比例或正常樣本標籤 |
| **高維適用** | 不受維度詛咒影響，適合高維嵌入向量 |
| **記憶體效率** | 使用子採樣策略，僅需部分資料建樹 |
| **可解釋性** | 樹狀結構可追溯異常發生的特徵維度 |

### 限制

| 限制 | 說明 |
|------|------|
| **局部異常偵測弱** | 對於在局部區域異常但全局分佈正常的點可能漏報 |
| **軸對齊切割** | 僅能進行平行於特徵軸的切割，對斜向分佈敏感度低 |
| **參數敏感性** | 樹的數量與子採樣比例影響結果穩定性 |

## 在本專案的應用

### 適用場景

Isolation Forest 在本專案中扮演**快速篩選器**的角色：

1. **嵌入空間異常**：識別在 BERT 嵌入向量空間中明顯偏離的日誌事件
2. **攻擊行為特徵**：惡意行為（如 Command Injection、異常檔案存取）通常在語義空間中較為稀疏
3. **初步異常候選**：為其他模型提供候選集，減少後續計算量

### 互補性貢獻

在 Ensemble 策略中，Isolation Forest 提供獨特的幾何視角：

| 模型 | 偵測角度 | 與 IF 的互補 |
|------|---------|-------------|
| COPOD | 統計機率 | IF 偵測幾何離群，COPOD 偵測機率異常 |
| AutoEncoder | 重構誤差 | IF 不依賴重建，可偵測 AE 難以學習的模式 |
| PCA+GMM | 密度估計 | IF 適合高維，GMM 適合特定分佈假設 |

### 日誌異常類型適用性

| 攻擊類型 | IF 偵測效果 | 原因 |
|----------|------------|------|
| **罕見指令執行** | ★★★★★ | 在指令嵌入空間明顯稀疏 |
| **異常路徑存取** | ★★★★☆ | 路徑模式在語義空間偏離正常 |
| **大量重複行為** | ★★☆☆☆ | 數量多反而形成密集區域 |
| **低強度持續攻擊** | ★★★☆☆ | 視行為與正常的語義距離而定 |

## 參數調整指南

### 關鍵參數

| 參數 | 建議值 | 影響 |
|------|--------|------|
| **樹的數量** | 100-200 | 越多越穩定，但計算時間增加 |
| **子採樣大小** | 256 或 auto | 過小降低準確度，過大增加耗時 |
| **contamination** | auto 或 0.01-0.1 | 預期異常比例，影響閾值決策 |

### 調整策略

- **誤報過多** → 增加樹的數量（穩定分數）、降低 contamination
- **漏報過多** → 提高 contamination、搭配其他模型補強
- **計算過慢** → 減少子採樣大小、降低樹的數量
